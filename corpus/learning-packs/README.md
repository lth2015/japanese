# Learning packs（/learning 语料包）

`/learning` 口语训练页的可导入语料包。与 `corpus/packs/`（`/display` 用、走 SQLite）
不同，这里的包面向 `/learning`，导入后存进浏览器 localStorage。

## 格式

一个 JSON 文件 = 一个数组，每项至少含 `zh` 和 `ja`：

```json
[
  { "zh": "我先去洗澡。", "ja": "先にお風呂に入ってくるね。", "kana": "さきにおふろにはいってくるね", "scene": "洗澡" }
]
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `zh` | ✅ | 中文提示 |
| `ja` | ✅ | 日语答案 |
| `kana` | | 假名读音 |
| `romaji` | | 罗马音 |
| `scene` | | 场景，建议用内置 12 个（起床/吃饭/出门/回家/洗澡/睡觉/情绪/拒绝/请求/确认/闲聊/工作）；缺省为「闲聊」 |
| `tags` | | 字符串数组 |
| `level` / `sm2` / `reviewCount` / … | | 完整导出时的进度字段，导入时会保留 |

## 导入方式

打开 `/learning` → 「语料」标签 → 「导入」按钮 → 选择本目录下的 JSON 文件。
导入的语料 id 会重新生成，不会覆盖已有语料。

「导出」按钮可把当前全部语料（含复习进度）下载为 JSON，作为备份或迁移。

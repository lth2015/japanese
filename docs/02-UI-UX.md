# 设计稿 02 — UI/UX 设计

> 调用 `ui-ux-pro-max` skill 拉取了 50+ 种风格、161 个色板、57 套字体配对的推荐数据。Skill 自动推荐了"Newsletter + Baloo 2/Comic Neue"——明显错配（那是儿童教育风），我覆盖为下面这套。

## 1. 设计哲学

三条原则，按优先级：

1. **能长时间看不累**。Display 模式可能在你副屏挂 8 小时。色彩饱和度低、对比柔和、动画极少。
2. **学习材料是主角，UI 是隐身的**。日语句子用大字号 serif 呈现，UI 元素用 sans 小字、低对比。
3. **每个交互都有触觉反馈**。录音、提交、加入复习——都有 0.95→1.0 的 scale 反馈和颜色 pulse。

设计风格关键词：**Modern Dark · Bento Grid · Ambient · Editorial**。
拒绝：Cyberpunk（霓虹太亮）、Glassmorphism（毛玻璃在小字上糊）、Skeuomorphism（土）。

## 2. 设计系统

### 2.2 字体

| 用途 | 字体 | 备注 |
|---|---|---|
| 日语正文（句子卡） | **Noto Serif JP** weight 500/700 | 衬线体让汉字结构清晰；用在大字号场景 |
| 日语 UI / 小字 | **Noto Sans JP** weight 400/500 | 按钮、菜单、表格 |
| 中文 / 英文 UI | **Inter** weight 400/500/600 | 配合中日混排 |
| 中文（不使用 Inter 兜底时） | **Noto Sans SC** weight 400/500 | fallback |
| 数字 / 时间 / 代码 | **JetBrains Mono** weight 400 | tabular figures，避免数字跳动 |

字体加载：
```css
/* app/layout.tsx 中通过 next/font 加载，避免 FOUT */
@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;500&family=Noto+Serif+JP:wght@500;700&family=Inter:wght@400;500;600&family=JetBrains+Mono:wght@400&display=swap');
```

Tailwind 配置：
```ts
fontFamily: {
  // CSS 中 font-family stack：日文优先 → 中文 → 拉丁兜底
  jp: ['"Noto Sans JP"', '"Noto Sans SC"', 'Inter', 'system-ui', 'sans-serif'],
  'jp-serif': ['"Noto Serif JP"', '"Noto Serif SC"', 'Georgia', 'serif'],
  sans: ['Inter', '"Noto Sans SC"', '"Noto Sans JP"', 'system-ui', 'sans-serif'],
  mono: ['"JetBrains Mono"', 'monospace'],
}
```

### 2.3 字号阶梯

| Token | Size | Line-height | 用途 |
|---|---|---|---|
| `text-display` | `clamp(2.5rem, 6vw, 5rem)` | 1.15 | Display 模式主句子（40-80px） |
| `text-hero` | `clamp(1.75rem, 3vw, 2.5rem)` | 1.2 | Drill 中文 prompt、跟读句子 |
| `text-h1` | `1.75rem` (28px) | 1.3 | 页面标题 |
| `text-h2` | `1.25rem` (20px) | 1.4 | 区块标题 |
| `text-body` | `1rem` (16px) | 1.6 | 正文（移动端最小 16，避免 iOS 缩放） |
| `text-sm` | `0.875rem` (14px) | 1.5 | 元信息、tag |
| `text-xs` | `0.75rem` (12px) | 1.5 | timestamp、ruby furigana |

### 2.4 间距系统（8pt）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`（Tailwind `space-1 ~ space-24`）。

**禁用任何非阶梯值**。如果 design 需要 13px 这种数字，不是 design 错了就是要换组件。

### 2.5 圆角

| Token | Size | 用途 |
|---|---|---|
| `rounded-sm` | 6px | tag、small button |
| `rounded` | 10px | input、select |
| `rounded-lg` | 14px | button、card 内嵌元素 |
| `rounded-xl` | 18px | card 默认 |
| `rounded-2xl` | 24px | hero card、Display 句子卡 |
| `rounded-full` | 9999px | 录音按钮、头像 |

### 2.6 阴影

深色 UI 上阴影不显眼，主要用 border。少数地方用 glow：

```css
--shadow-card: 0 1px 0 rgba(255,255,255,0.04) inset;   /* 卡片顶部 1px 高光，仿 Linear */
--shadow-accent-glow: 0 0 0 6px var(--accent-glow);     /* primary button focus */
--shadow-elevated: 0 8px 32px rgba(0,0,0,0.5);          /* 弹窗 */
```

### 2.7 动效

| 场景 | 时长 | Easing |
|---|---|---|
| Press（按钮、卡片） | 100ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| Hover | 150ms | `ease-out` |
| 页面切换 | 250ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| Display 句子切换（crossfade） | 600ms | `ease-in-out` |
| 录音脉动 | 1200ms 循环 | `ease-in-out` |
| Toast | enter 200ms / exit 150ms | `ease-out` / `ease-in` |

**所有动画必须 `prefers-reduced-motion: reduce` 时退化为 0ms**。

### 2.8 图标

- **Lucide React**（已经是 shadcn/ui 默认）
- 大小：`16 / 20 / 24` 三档
- stroke width 固定 `1.75`
- **零 emoji 作为功能图标**（用了视觉就破）

### 4.2 Display 模式 `/display`

**目的**：放在第二屏 / 手机挂机。零交互、零干扰。

```

│   〈                                              ⏯              〉│
└────────────────────────────────────────────────────────────────────┘
   queue progress dots                              prev / pause / next
```

**视觉**：
- 全屏 bg-deep `#080B14`
- 日语 `text-display`，font-jp-serif，颜色 `text-primary`
- 假名 `text-h2`，font-mono，颜色 `text-muted`，字间距宽松
- 中文 `text-h2`，font-sans，颜色 `text-secondary`
- 三行之间间距 `gap-12`（48px）

**交互**：
- 移动鼠标 / 触碰屏幕：底部控制条淡入（200ms），3 秒无操作淡出
- 键盘 `←/→` 切换、`Space` 暂停
- 设置入口（齿轮）只在 hover 显示
- 设置面板（Sheet 从右侧滑入）：
  - 队列源（今日复习 / 全部预置 / 某个分类 / 自建）
  - 切换间隔（4-15s 滑块）
  - 字号（S/M/L/XL）
  - 是否显示假名（开关）
  - 是否显示中文（开关）
  - 是否自动 TTS 播放（开关）
  - 深度专注模式（隐藏所有 UI，只留键盘控制）

**切换动效**：crossfade 600ms。下一句**预加载 TTS** 在当前句剩 1.5s 时开始 fetch。

**Wake Lock**：进入 Display 模式立即请求屏幕常亮。

- 用户气泡右对齐，`bg-accent`（深色背景上 60% opacity，accent + 自身 backdrop-blur）
- 每条 AI 句子带 ▶ 播放按钮（用缓存的 TTS）
- 录音按钮固定底部，宽度 80px（小于跟读页的 100px，因为对话中录的更频繁）
- "提示" 按钮：用了之后会扣一点本轮分数，但能避免完全卡壳——展示一个引导词或片段
- 结束对话 → 跳转到总结页

## 5. 移动端关键差异

| 元素 | Desktop | Mobile |
|---|---|---|
| 导航 | 左侧 sidebar（宽 240px） | 底部 tab（高 64px + safe area） |
| 录音按钮 | 80-100px | 100px，按住为主交互 |
| Dashboard | bento 3 列 | 1 列堆叠 |
| Display 字号 | 80px max | 48px max（保证短句一行内） |
| Drill 输入 | 多行 textarea | 单行 + 自动换行 |
| 反馈面板 | 同页展开 | Sheet 从下滑入 |

**关键**：所有触摸目标 ≥44×44px，下沿与底部 nav 至少 16px 间距。

## 6. 可访问性核查清单

- ✅ 所有触摸目标 ≥44px
- ✅ 文字对比 ≥4.5:1（已验证 §2.1）
- ✅ 录音按钮有 aria-label，状态变化时 aria-live 公告
- ✅ 颜色不是唯一信息载体（success/danger 都配图标）
- ✅ 键盘可达所有功能（含 Display 模式 `←/→/Space`）
- ✅ focus ring 2-4px，颜色 `--ring-focus`
- ✅ 尊重 `prefers-reduced-motion`（轮播退化为立即切换，pulse 停止）
- ✅ 尊重 `prefers-color-scheme`（v1 强制 dark，但记录用户偏好供 v2）
- ✅ 表单错误用 role="alert"

## 7. 字符 / 假名 / 汉字注意

- 日语 ruby（振り仮名）用 HTML `<ruby>` 标签：
  ```html
  <ruby>確認<rt>かくにん</rt></ruby>
  ```
  V1 在跟读和 Display 模式启用，可在设置中关闭
- 假名标注用 `text-xs font-mono text-muted`，避免和主文字争夺注意
- 句末标点 `。` 不要省，但句子卡里**居中显示时**视觉上要做 visual hanging punctuation

## 8. 暂时不做（v2 候选）

- Light mode（个人项目，先把 dark 做到极致）
- 个人头像上传（用 initials 圆形头像就够）
- 主题色自定义
- 多设备同步状态指示
- 学习日历热力图（数据少，没意义）
- 排行榜（个人 app 不需要）
